# delphis-assets

Archivos públicos pesados de [Delphis Method](https://delphis-55733.web.app) (vídeos de teoría, y lo que se añada), servidos gratis vía [jsDelivr](https://www.jsdelivr.com/) en vez de por Firebase Hosting, para no gastar su cuota de transferencia.

Esto **no es el código de la aplicación** (ese vive en un repositorio privado aparte). Solo son archivos estáticos sin lógica ni datos de usuarios.

## Vídeos de teoría

Los vídeos de las lecciones de gramática no están en el árbol de este repositorio (jsDelivr limita a 50 MB el contenido total por commit). Están como adjuntos del Release `teoria-videos`, enlazados directamente desde `js/teoria-leccion.js` en el repositorio principal.
